本次重名问题的根因是三个导入服务历史上只按员工姓名匹配：

- `HrmPersonalIncomeTaxService#resolvePersonalIncomeTaxData`
- `HrmAdditionalService#resolveAdditionalData`

## 代码修复

新增公共匹配器：

- `TaxImportEmployeeMatcher#resolveEmployeeId(...)`
  - 有手机号：按姓名 + 手机号精确匹配；
  - 无手机号：仅当姓名唯一时兼容旧模板；
  - 无手机号且重名：报错要求补手机号；
  - 姓名 + 手机号找不到：报错，不猜测员工。
- `TaxImportEmployeeMatcher#ensureUniqueEmployeePeriod(...)`
  - 导入同一文件内同一员工同一年月或同一年重复时直接报错。

三个导入接口已改为异常时返回 `Result.Error(...)`，不再打印异常后仍返回成功。
